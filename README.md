# 팀 업무 공유판

인사팀 팀원 전체가 지금 하고 있는 업무를 함께 보고 공유해 누락 없이 진행하기 위한 웹 서비스입니다. 가상 데이터로 시연합니다.

- 설명서: [PRD.md](PRD.md) · 정의: [정의.md](정의.md)
- 만든 것: 대시보드(첫 화면) · 업무 입력(오른쪽 패널, 「기타」 글 입력) · 팀 업무 목록 · 저장 · 시연용 사람 선택과 담당자 추가 · 업무 수정·삭제(삭제는 삭제 표시만, 되돌리기 가능) · 월간/주간 캘린더(처음엔 주간). 하루 업무량(기능 5)과 주간 정리(기능 6)는 아직 없습니다.
- 휴일 목록: [휴일.csv](휴일.csv) (구글 캘린더 「대한민국의 휴일」, 2025~2030). 2028~2030년은 빠진 날이 있을 수 있습니다(PRD 「남은 확인 필요」).

## 실행

```bash
npm install
cp .env.example .env.local   # 값은 소유자에게 받아 채웁니다
npm run dev
npm run test
```

## 알아 둘 것

- 로그인이 없는 시연용입니다. 권한(자기 업무만 고치기)은 화면에서만 나뉘고, 저장소는 공개 키로 읽고 쓸 수 있습니다. 실제 회사 데이터는 넣지 않습니다.
- 저장소 표와 접근 규칙은 Supabase 마이그레이션으로 만들었습니다(업무 · 구분 · 담당자 · 변경 기록).
